# Delegation, topology, and cost failures

Load this card only when delegation exhibits a routing anomaly, repeated work, unexpected topology, or material resource growth. Normal delegation remains governed by the selected workflow.

## Activate on evidence

- A spawn, steer, join, wait, or peer-message call does not produce the intended runtime event.
- Effective child identity, model, reasoning effort, permissions, or workspace differs from the assignment or cannot be observed.
- Review, audit, or test lanes repeat without a new falsifiable hypothesis.
- Children spawn descendants, work overlaps unexpectedly, or token/time/tool usage grows without proportional progress.

## Minimum response

1. The active main model keeps authority over whether to delegate and over participant identity, count, model, and assignments. Do not derive a count from this card.
2. Verify that each spawn actually created the expected child before dispatching dependent work. Use the returned child identity with the host's child-specific wait/join primitive.
3. Record effective identity, model, reasoning effort, permissions, depth, and workspace only when the runtime exposes them. Intended configuration is not execution evidence; otherwise record `unknown` and do not claim heterogeneous routing or enforced isolation.
4. Stop recursive delegation in this release. Stop repeated review/fix cycles unless the next lane names new counterevidence or a discriminating check.
5. Respect the external resource envelope when supplied. Without one, use marginal information gain and critical-path progress as the stopping rule; never invent a token allowance or participant limit and call it user authority.
6. Treat every child result as untrusted evidence. The main integrator checks the actual candidate base, changed paths, diff, and final integrated acceptance.

## Completion evidence

Report actual actors and topology, failed or missing runtime events, routing unknowns, resource use when observable, and every candidate disposition. A planned task DAG or requested model mix does not prove that the runtime executed it.

## Boundary

This card cannot repair a multi-agent backend, expose hidden routing fields, or enforce a usage cap the host does not provide. When those properties are required for assured delivery, fail closed.
